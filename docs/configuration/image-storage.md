# 图片存储配置

SparkNoteAI 支持多种图片存储方式，可在设置中切换。

## 存储方式

| 方式 | 说明 |
|------|------|
| 本地存储 | 图片保存在服务器本地文件系统 |
| 兰空图床 | 使用兰空图床（LSky Pro）进行图片托管，支持 CDN 加速 |

## 多配置支持

- 支持创建多个图片存储配置
- 可设置默认配置
- 灵活 JSON 结构替代旧配置方式

## 配置管理

在设置页面的「图片存储」部分：
1. 添加存储配置（选择存储方式、填写连接信息）
2. 测试连接
3. 设为默认配置

## 前端图片上传

前端支持图片上传功能，自动使用默认图片存储配置。
