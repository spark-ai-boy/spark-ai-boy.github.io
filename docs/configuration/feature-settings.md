# 场景功能配置

`FeatureSetting` 模型用于管理各功能场景的配置，实现场景与 LLM 等资源的灵活绑定。

## 支持的场景

| 场景 | 说明 |
|------|------|
| 知识图谱 | 配置图谱构建和概念提取使用的 LLM |
| AI 助手 | 配置助手对话使用的 LLM 模型 |
| 内容摘要 | 配置笔记自动摘要使用的 LLM |

## 配置方式

- 每个场景独立配置，可选择不同的 LLM 配置
- 通过 `/api/feature-settings` API 管理
- 前端在设置页面提供可视化配置界面
- 支持配置分组和动态扩展

## 使用场景示例

假设你同时配置了 GPT-4 和 Claude 两个 LLM：

- 知识图谱提取使用 GPT-4（概念提取能力强）
- AI 助手对话使用 Claude（对话体验更好）
- 内容摘要使用成本较低的模型
