# 笔记管理

笔记管理是 SparkNoteAI 的核心功能之一，提供完整的 Markdown 编辑、标签分类和导出能力。

## 功能特性

### Markdown 编辑器

- 基于 md-editor-rt 的 Obsidian 风格 Markdown 编辑器
- 实时预览，左右分栏或上下跟随模式
- 格式化工具栏：标题、粗体、斜体、代码块、列表等
- 代码语法高亮支持

### 标签系统

- 为笔记添加标签，支持标签颜色自定义
- 侧边栏标签过滤，按标签筛选笔记
- 标签管理界面支持创建、编辑和删除标签
- 删除标签时有确认对话框防止误操作

### 笔记列表

- 三栏布局：左侧标签 + 中间笔记列表 + 右侧编辑器
- 实时预览和内容详情展示
- 支持按标签过滤笔记

### 导出

- 支持将笔记导出为 ZIP 文件
- 包含 Markdown 源文件和相关资源

笔记相关 API 均通过 `/api/notes` 端点访问，支持分页查询。详细接口请参考 [API 参考 - 笔记](../api-reference/notes)。
