# Mind Map

The mind map provides a standalone visual view of knowledge structure.

## Features

- Displays knowledge hierarchy in a tree structure
- Supports expanding/collapsing nodes
- Adjustable node layout
- Linked with note and knowledge graph data

## Use Cases

- Quickly browse the overall knowledge structure
- Organize hierarchical relationships between notes
- Serve as a supplementary view to the knowledge graph
