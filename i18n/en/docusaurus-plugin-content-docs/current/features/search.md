# Smart Search

Smart search provides global search capability to quickly locate notes, tags, and content.

## Features

- Full-text search: searches through note titles and content
- Tag filtering: filter search results by tag
- Real-time response: displays matching results as you type
- Global entry point: unified search entry in the navigation bar

## How to Use

1. Click the search icon in the navigation bar
2. Enter keywords
3. Browse search results and click to navigate to the corresponding note
